# Data Dictionary & Schema Definition

This data dictionary defines the exact schema, data types, and unit definitions for the master CSV and Excel datasets stored in the `results/` directory of this repository.

---

## 1. Latency & Telemetry Datasets (`rtf_telemetry_master.csv`)
Contains raw iteration-level hardware telemetry and execution latency metrics for all evaluated TTS models.

| Column Name | Data Type | Description & Unit |
| :--- | :--- | :--- |
| `Modell` | String | Unique identifier of the evaluated TTS model / configuration |
| `Satz_ID` | String | Standardized test sentence identifier (`K01`–`K10`, `M01`–`M10`, `H01`–`H18`, `L01`–`L05`) |
| `Kategorie` | String | Linguistic category (`Kurzbefehl`, `Standard`, `Kompositum`, `Zahlen_Einheiten`, `Homograph`, `Abkuerzung`, `Intonation`, `Anglizismen`, `Langtext`) |
| `Text` | String | Graphemically normalized German target text string |
| `Zeichen` | Integer | Total character count of the input text string (including whitespace/punctuation) |
| `Iteration` | Integer | Benchmark iteration run index (1 to 3) |
| `Temp_Start_C` | Float | SoC core temperature at the exact start of synthesis ($\,^\circ\text{C}$) |
| `Temp_End_C` | Float | SoC core temperature immediately after synthesis completion ($\,^\circ\text{C}$) |
| `Throttled_Flag` | Hex / String | Raspberry Pi firmware throttling register flag (`vcgencmd get_throttled`) |
| `Synthesezeit_s` | Float | Pure algorithmic inference compute time measured via `perf_counter()` (seconds) |
| `Audio_Dauer_s` | Float | Duration of the generated audio waveform (seconds) |
| `RTF` | Float | Real-Time Factor ($\text{Synthesezeit} / \text{Audio-Dauer}$ dimensionless ratio) |
| `Audio_Pfad` | String | Relative storage path to the exported reference WAV file |

---

## 2. Intelligibility Datasets (`wer_cer_evaluation.xlsx`)
Contains Faster-Whisper transcription accuracy metrics evaluated via Levenshtein distance (`jiwer`).

| Column Name | Data Type | Description & Unit |
| :--- | :--- | :--- |
| `model` | String | Evaluated TTS model identifier |
| `Prompt_ID` | String | Test sentence identifier |
| `Kategorie` | String | Linguistic category |
| `Original_Referenz`| String | Ground-truth normalized reference text from `textcorpus_de.csv` |
| `Whisper_Verbalisiert`| String | Re-transcribed text output generated by Faster-Whisper (large-v3) |
| `S_Substitutions` | Integer | Number of substitution errors |
| `D_Deletions` | Integer | Number of deletion errors |
| `I_Insertions` | Integer | Number of insertion errors |
| `H_Hits` | Integer | Number of correct word matches (hits) |
| `N_Words` | Integer | Total word count in reference text |
| `Satz_WER` | Float | Word Error Rate (WER) ratio per sentence |
| `Satz_CER` | Float | Character Error Rate (CER) ratio per sentence |

---

## 3. Acoustic Quality & Naturalness Datasets (`mos_nisqa_utmos_predictions.xlsx`)
Contains deep-learning predicted Mean Opinion Scores (MOS).

| Column Name | Data Type | Description & Unit |
| :--- | :--- | :--- |
| `Prompt_ID` | String | Test sentence identifier |
| `Kategorie` | String | Linguistic category |
| `deg` | String | Filename of the evaluated degraded audio sample |
| `mos_pred` | Float | Predicted MOS score (scale 1.0 to 5.0) |
| `model` | String | Evaluated Quality Estimator framework (`NISQA_TTS_v1` or `UTMOSv2`) |
